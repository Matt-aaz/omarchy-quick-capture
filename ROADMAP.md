# Quick Capture roadmap

v0.1 intentionally implements one reliable path: summon, type, append Markdown, and return.

## v0.2 candidates

Prioritize these only from actual user feedback:

- Capture modes: Quick / Reading / Quote / Idea
- Editable tags
- Multiple destination files
- Daily-file mode
- Browser title and URL capture
- Selected-text capture
- Clipboard capture
- Multiple templates
- Markdown preview
- Recent captures
- Undo last capture
- Optional Obsidian URI actions
- Optional bar widget
- Optional graphical settings panel
- Configurable post-save hooks
- Per-project destinations
- Optional CLI capture

## Recommendation

Start with editable tags and daily-file mode only if repeated use shows they reduce capture friction without adding a mode-selection step. Treat browser and clipboard integrations as opt-in privacy-sensitive features. Keep AI, sync, and cloud services out of the default product.
